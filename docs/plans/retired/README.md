# Retired — superseded / abandoned plans

Plans in this folder were **explicitly superseded** by a different
direction or **abandoned** as a design choice. They're preserved for
historical context (so the design history doesn't disappear and so a
future session sees "this was tried, here's why we changed course")
but **do not implement them.**

Each retired plan should open with a short callout naming what
replaced it.

For active work, see [`docs/plans/current.md`](../current.md).
