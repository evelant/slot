# Done — shipped plans

Plans in this folder describe work that **fully shipped**. They're
preserved as design references — the architecture, motivation, and
trade-off discussion are still useful for understanding why the code
looks the way it does — but the work itself is closed and there's
nothing left to implement from them.

If a topic in one of these plans needs further work, it gets a fresh
plan in `docs/plans/` rather than re-opening one of these.

For active work, see [`docs/plans/current.md`](../current.md). For the
operational handoff, see [`docs/status.md`](../../status.md).
